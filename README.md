# NEURAL//RACE

A futuristic circuit racing game built with React and Three.js.

## Run locally

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

The production files are written to `dist/`.

## Deploy on GitHub Pages

This repository includes a GitHub Actions workflow that builds the game and publishes `dist/` to GitHub Pages whenever changes are pushed to `main`.

In the repository settings, open **Pages** and set the source to **GitHub Actions**. After the workflow completes, GitHub will show the live site URL on that page.
